# Office Artifacts: The One-Line Placard Contest

A one-line museum placard for an ordinary office object, written as if it were an ancient artifact — in the dry voice of a museum curator who has read ten thousand labels and laughed at six.

## The entry

> Hole punch, c. 2018. Steel. It punched two neat holes in every memo it met, including the one that abolished it.

The placard lives in `entry.txt` (112 characters, one line).

## How to run

Requires Node 22. No dependencies.

```sh
node main.ts
```

This copies `entry.txt` to `/output/entry.txt`, creating `/output` if needed.
